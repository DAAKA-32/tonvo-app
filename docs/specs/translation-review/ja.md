# Translation review: 日本語 (ja)

Reviewer: native speaker of the language, ideally with some marketing or legal reading experience.

How to review

1. Read each row. If the translation is fine, write `OK` in the last column. If not, write the corrected text there.
2. Check that it sounds natural to a native reader, uses the register of the rest of the site, and keeps the meaning of the English (no softer, no stronger, no added promise).
3. Product terms stay as they are: **Tonvo**, **Free**, **Plus**, **Team**, prices in **$ / USD**.
4. Search results: a title should stay within about 30 characters and a description within about 80 (the length is shown). They are what people see on Google before clicking.
5. Variables such as `{{plan}}` must stay unchanged.
